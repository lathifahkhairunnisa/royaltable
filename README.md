# eatstime — Royal Table
Game restoran fine-dining HTML/CSS/JavaScript, siap GitHub Pages.

Fitur: 16 menu, foto hidangan nyata dari Unsplash (bukan placeholder), kategori, keranjang, checkout, sistem tip, combo, reputasi, daily goal, modal cara main, localStorage, responsive desktop/tablet/HP.

Deploy: extract ZIP → upload index.html, style.css, script.js → GitHub repo → Settings → Pages → pilih branch utama + /root → Save.

Catatan: gambar menggunakan URL Unsplash, jadi koneksi internet diperlukan agar foto menu tampil.
